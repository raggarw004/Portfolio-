Projects[:4]

Evolutionary Neural Architecture Search

01

A from scratch NAS system that evolves CNN architectures on FashionMNIST instead of hand tuning them. A genetic algorithm mutates and crosses over depth, channel widths, kernel sizes, batch norm, dropout, and hidden size across generations, scoring each candidate on validation accuracy with a parameter count penalty to favor efficient networks over just the biggest ones.

pytorchnasgenetic-algorithm

Behavior Sequence Lab

02

A real-time FastAPI service that classifies user interaction state — focused, tired, confused, or expert — from mouse and typing telemetry. A bidirectional LSTM with attention pooling scores each session, and an HMM-style transition layer smooths predictions across time so the model doesn't flicker between states on noisy single readings.

pytorchbilstmfastapi

Cooperative Multi-Agent PPO

03

A shared policy PPO implementation where multiple agents learn to cooperatively cover targets on a grid, trained from scratch with generalized advantage estimation and PPO's clipped objective. Reward shaping balances individual contribution against team success, with a collision penalty that pushes agents toward implicit coordination rather than just racing each other to targets.

pytorchppomulti-agent-rl

AI Trading Signal Model

04

An LSTM-Transformer ensemble in PyTorch that fuses bidirectional LSTM and positional-encoded Transformer outputs to predict returns. Backtested out-of-sample with configurable transaction costs, tracking Sharpe ratio, drawdown, hit rate, and a confusion matrix.

pytorchlstmtransformer
